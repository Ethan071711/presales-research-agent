# 公开业务资料与应用规则

公开资料核对日期：2026-10-24。产品字段由人工从 [PA Power 产品页](https://papower.com.au/products) 及对应套餐页整理；字段来源和核对日期保存在 `data/sources.json`，每条产品和知识记录也附有来源。

## 数据如何使用

20 条是供应商公开展示的**完整套餐标签**，包含逆变器/系统功率及电池容量。功率不是已验证的离网输出；网站没有统一说明容量是名义还是可用电量，因此代码用 `advertised_capacity_kwh`，不据此自动计算备电时长或模块数。原品牌/型号名称保留，未借用厂商标识、照片或客户资料。

其中 15 条允许作为售前候选；5 条隔离：

- Fox 三相 EP11 栏目写 KH，厂家 [KH/KA 资料](https://www.fox-ess.com/wp-content/uploads/2024/12/EN-KH-KA-Datasheet-V2.0-20241127.pdf) 标明单相。保留原始矛盾，不擅自把 KH 改为 H3。
- Tesla 栏目的套餐容量没有明确对应台数、相制与组件配置，暂停自动推荐。

网站页面可能变化。这是一次带日期的整理，不是实时库存、供应商授权目录或完整兼容表。每次正式使用前应复核精确型号、厂家兼容文件和当前在售情况。

## 哪些是应用自己的规则

需求表单、相制/容量/功率初筛、旧光伏和备电核对清单、冲突隔离、经理审核属于本应用实现。知识库的 `application_guide` 类型会写明“本应用”。它们不冒充 PA Power 的折扣、交期、保修、付款政策或公司内部制度。

`data/public_offers.json` 收录一条 [商家关联账号公开促销](https://www.ozbargain.com.au/node/977206)，发布日期 2026-10-01、核对日期 2026-10-25：HYXI E200 + HYX-H10K-HT 三相 21.2 kWh / 10 kW，AUD 3157。该型号独立建档，不能对应到 H8K + E50B-H1 单相型号。商家所述金额含 GST、标准安装和符合资格后的电池优惠；资格、库存、勘测与额外工程尚未确认，备电选项需另议。商家要求在 2026-11-01 前安装，应用据此停止使用窗口外的参考金额，不擅自假设另一报价有效期。

公开条件价填入 `public_reference`，状态为 `reference_for_review`，`total_aud` 和 `known_amount_aud` 仍为 `null`、预算仍未验证。安装窗口结束后回到 `awaiting_price`。有效的组织私有价格单优先。其他缺价套餐仍显示待询价，绝不是 0 澳元。取得真实价格单后，可用 `PRESALES_PRICEBOOK` 指定私有 JSON 文件，重启应用载入。文件不要提交到 GitHub。

价格单是一个数组，每条须有以下字段：

| 字段 | 要求 |
|---|---|
| tenant | `demo-a` 或 `demo-b`，只供对应组织报价 |
| product_id | 公开目录中的套餐 ID |
| currency | `AUD` |
| amount_cents | 正整数澳分，金额从有效价格单录入 |
| scope | `equipment_only` 或 `installed_system` |
| gst_included | 是否明确含 GST |
| expires_on | 价格单给出的有效日期，YYYY-MM-DD |
| reference | 可追溯的供应商报价单编号或来源说明 |

缺价、过期、仅设备价、未含税分别处理；只有有效的含税完整安装价格才填 `total_aud`。测试里的金额是专门的测试输入，不是供应商报价，不在默认页面启用。不会把商家列出的优惠条件当作已核实的客户补贴资格，也没有现货或统一有效天数的假设。

## 评测和权限数据

新增公开报价套餐未改写既有 200 条问题和答案；其型号、金额状态、窗口边界与隔离由单独测试覆盖。

200 条是新编的选型资料检索题，40 条越权测试单独存放。二者都不是历史客户问题。权限测试文档使用显式的合成哨兵内容，验证跨组织、跨角色不泄漏。

Recall@5 统计目标资料是否进入前五，不能当作推荐正确率或生成回答正确率。题目和小型资料库同源且包含模板改写；应另外收集独立用户问题才可讨论泛化。
